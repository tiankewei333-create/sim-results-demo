# Pulse Forecast

Upwork-style demo: collect user inputs → validate → show simulated monthly revenue results.

## Run locally

```bash
cd D:\projects\sim-results-demo
npm install
npm run dev
```

## Deploy (Vercel)

```bash
npx vercel
```

Or connect the folder to Vercel / Netlify and use `npm run build` → `dist`.

## Stack

React + TypeScript + Vite + React Hook Form + Zod
